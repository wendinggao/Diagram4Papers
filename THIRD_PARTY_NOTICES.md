## AutoGPS scientific content source

The independently drawn example is based on Bowen Ping et al., *AutoGPS: Automated Geometry Problem Solving via Multimodal Formalization and Deductive Reasoning*, ICLR 2026, https://arxiv.org/abs/2505.23381, Sections 3.3–3.4, Algorithm 1 and Figure 3. The public geometry problem uses sides 13, 13 and 10. New native geometry, diagrams and explanatory wording are authored for this example. No PDF artwork, extracted paths, paper screenshots or implementation source code are redistributed. The illustrative derivation is not a captured solver trace. Detailed sources and limitations are in `examples/design-notes.md`.

## Voyager example and adapted program

The second example is informed by Guanzhi Wang et al., *Voyager: An Open-Ended Embodied Agent with Large Language Models*, 2023, https://arxiv.org/abs/2305.16291, Sections 2.1–2.3 and Figures 2–6. The chest-crafting scenario, model responses, vectors and retrieval list are illustrative; no source figure, game screenshot or Minecraft texture is shipped. The native scene is independently drawn.

The short functional program adapts `skill_library/trial1/skill/code/craftChest.js` and the documented control interface from [MineDojo/Voyager](https://github.com/MineDojo/Voyager), revision `55e45a880755d0c8c66ca7fb5fe7962ac8974f89`. Copyright (c) 2023 MineDojo Team, MIT License. The program is shortened, uses the current plank count and assumes a crafting table is nearby. Retain [the upstream license notice](references/voyager-code-license.txt) with this adapted excerpt. Its offline mock is neither the original environment nor a recorded model run.
